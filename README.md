# The Odyssey — five-minute film

A cinematic web player for Homer’s *Odyssey*: a timed five-minute cut with chapter stills, on-screen narration, and a full-bleed dark-gold frame.

**Live site (GitHub Pages):** https://inodeman.github.io/the-odyssey-short/

## Run locally

Open `index.html` in a browser. No build step.

## Enable Pages

If the live URL is not up yet:

1. Repo **Settings → Pages**
2. Source: **GitHub Actions**
3. Re-run the *Deploy GitHub Pages* workflow

## Credit

Text adapted from Homer. Paintings are public-domain works (Waterhouse, Turner, Jordaens, Böcklin, Degeorge, and others) loaded from Wikimedia Commons.
